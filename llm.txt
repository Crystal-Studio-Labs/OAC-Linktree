## 🛠️ HOW TO MANAGE LINKS (`src/data/links.ts`)

All links displayed on the page are defined in the `LINK_ITEMS` array inside `src/data/links.ts`.

### 1. Link Data Structure (`LinkItem`)

```typescript
export interface LinkItem {
  id: string;               // Unique identifier (e.g. 'ocd-tickets-2026')
  title: string;            // Primary card heading
  subtitle?: string;        // Short 1-2 sentence description
  url: string;              // Destination URL
  isFeatured?: boolean;     // [IMPORTANT] true = Large Hero Banner Card | false = Compact Row Card
  badge?: string;           // Pill badge text (e.g. '🔥 TICKETS LIVE', '🌟 AUDITIONS')
  badgeColor?: 'red' | 'gold' | 'emerald' | 'purple' | 'blue'; // Badge accent color
  thumbnailUrl?: string;    // Image path (e.g. '/images/my-poster.png') or full URL (optional)
  highlightGlow?: boolean;  // Accent glow styling (optional)
  actionText?: string;      // Button label (e.g. 'Book Tickets', 'Apply Now')
  iconName?: string;        // Lucide icon name fallback if no thumbnail (e.g. 'Ticket', 'Mic', 'Store')
}
```

### 2. Badge Color Semantics
When configuring `badgeColor`, follow these brand standards:
- `'red'`: Flagship passes, urgent deadlines, live tickets (`#D91515`)
- `'gold'`: Official spotlights, talent hunt, stage auditions (`#F3B334`)
- `'purple'`: Parties, seasonal/Halloween specials, nightlife
- `'emerald'`: Vendors, stall registrations, active community chats
- `'blue'`: Gaming tournaments, Discord server, voice lounges

---

## 🌟 THE `isFeatured` OPTION EXPLAINED

Every link card supports the `isFeatured` boolean:

- **`isFeatured: true`**:
  Renders the link as an **Expanded Spotlight Hero Card** with a large, wide 16:9 poster banner across the top, prominent typography, pulsating live radar badge, and maximum visual prominence. Use this ONLY for the #1 flagship event or top-priority announcement.

- **`isFeatured: false`** (or omitted):
  Renders the link as a **Sleek Compact Row Card** with a small 56x56 square thumbnail/icon on the left side. Use this for regular event passes, forms, and community channels.

## ⚡ SHORTCUT REDIRECT SYSTEM ("WARP ROUTING")

The application supports automated direct shortcut redirects via URL query parameter or hash:
- `?go=tickets` → Warps directly to the tickets pass URL.
- `?go=discord` → Warps directly to the Discord invite.
- `?go=whatsapp` → Warps directly to the WhatsApp invite.
- `?go=halloween` → Warps directly to the Halloween passes.

When adding a new link, ensure its `id` is descriptive so it can be easily targeted via `?go=<id>`.

## 🖼️ HANDLING IMAGES & THUMBNAILS

- **Recommended Dimensions**:
  - Banner images (`isFeatured: true`): 16:9 aspect ratio (`1200x675px` or `800x450px`).
  - Square thumbnails (`isFeatured: false`): 1:1 aspect ratio (`400x400px` or `500x500px`).
- **File Storage**:
  1. Save image assets inside: `public/images/<image-name>.<ext>`
  2. Reference the image in `src/data/links.ts` as `thumbnailUrl: '/images/<image-name>.<ext>'`
  3. The internal asset resolver automatically handles subpaths for GitHub Pages hosting.
